6 Análisis de Ranking: Cambios en la Posición de las Causas de Muerte

El ranking de causas de muerte no es estático. Analizar cómo cambia la posición relativa de cada causa a lo largo del tiempo permite identificar qué enfermedades ganan o pierden importancia en la carga de mortalidad.

6.1 Ranking de causas por año

top10_tasas <- datos %>%
  filter(causa != "All causes") %>%
  group_by(causa) %>%
  summarise(tasa_promedio = mean(tasa_ajustada, na.rm = TRUE)) %>%
  arrange(desc(tasa_promedio)) %>%
  slice_head(n = 10) %>%
  pull(causa)

# 2. Calcular tasa nacional promedio por año 
datos_tasas_nac <- datos %>%

# 3. Verificar rango de tasas

Interpretación: La gráfica deja ver dos dinámicas simultánea que no deben leerse por separado. Por un lado, las enfermedades cardíacas caen de forma pronunciada de aproximadamente 267 a 165 por 100,000, lo que representa la reducción más significativa del período en términos absolutos; esta caída es atribuible a políticas sostenidas de prevención cardiovascular, expansión del acceso a estatinas y mejoras en la atención del infarto agudo.

El cáncer, en cambio, apenas varía (de ~200 a ~163), señal de que los avances oncológicos compensan el incremento poblacional de riesgo, pero sin lograr una reducción comparable. Por otro lado, las lesiones no intencionales que en 1999 eran la 5ta causa muestran una aceleración desde 2014 que rompe la tendencia del resto de causas.Este quiebre no es aleatorio, coincide con el auge de las sobredosis por opioides sintéticos como el fentanilo en el mercado ilegal. Que una causa ligada a factores sociales y de política de drogas supere en crecimiento a todas las enfermedades crónicas es la señal más relevante del período y la que más debería orientar la respuesta de salud pública.

El Alzheimer merece mención aparte, su crecimiento no obedece a un empeoramiento epidemiológico sino a la combinación del envejecimiento de los baby boomers y a mejoras en el diagnóstico que antes clasificaban estas muertes bajo otras causas. Su ascenso en el ranking es real.

6.2 Cambios en el ranking: 1999 vs 2017

library(dplyr)
library(knitr)
library(kableExtra)

if (!exists("datos_nacional")) {
  datos_nacional <- datos %>%
    filter(causa != "All causes") %>%
    group_by(anio, causa) %>%
    summarise(muertes = sum(muertes, na.rm = TRUE), .groups = "drop")
}

# 1. Calcular ranking por año (excluyendo "All causes")
ranking_anual <- datos_nacional %>%
  group_by(anio) %>%
  mutate(rank = rank(-muertes, ties.method = "min")) %>%
  ungroup()

# 2. Extraer rankings de 1999 y 2017
rank_1999 <- ranking_anual %>%
  filter(anio == 1999) %>%
  select(causa, rank_1999 = rank, muertes_1999 = muertes)

rank_2017 <- ranking_anual %>%
  filter(anio == 2017) %>%
  select(causa, rank_2017 = rank, muertes_2017 = muertes)

# 3. Unir y calcular cambios
cambios_ranking <- inner_join(rank_1999, rank_2017, by = "causa") %>%
  mutate(
    cambio_rank = rank_2017 - rank_1999,
    cambio_muertes = muertes_2017 - muertes_1999,
    pct_cambio = (muertes_2017 - muertes_1999) / muertes_1999 * 100,
    cambio_formateado = case_when(
      cambio_rank < 0 ~ paste0("▲ ", abs(cambio_rank)),
      cambio_rank > 0 ~ paste0("▼ ", cambio_rank),
      TRUE ~ "="
    ),
    dir_cambio = case_when(
      cambio_rank < 0 ~ "up",
      cambio_rank > 0 ~ "down",
      TRUE ~ "same"
    ),
    dir_pct = case_when(
      pct_cambio > 0 ~ "up",
      pct_cambio < 0 ~ "down",
      TRUE ~ "same"
    )
  ) %>%
  arrange(desc(abs(cambio_rank)), rank_1999)

tabla_cambios <- cambios_ranking %>%
  select(causa, rank_1999, rank_2017, cambio_formateado, pct_cambio) %>%
  mutate(pct_cambio = round(pct_cambio, 1)) %>%
  rename(
    "Causa" = causa,
    "Rank 1999" = rank_1999,
    "Rank 2017" = rank_2017,
    "Cambio" = cambio_formateado,
    "Variación %" = pct_cambio
  )

tabla_cambios %>%
  kable(
    caption = "Cambios en el ranking de causas de muerte (1999-2017)",
    
    
    align = c("l", "c", "c", "c", "r"),
    escape = FALSE
  ) %>%
  kable_styling(
    bootstrap_options = c("striped", "hover", "condensed"),
    full_width = FALSE,
    position = "center",
    font_size = 12
  ) %>%
  column_spec(4, 
    color = ifelse(cambios_ranking$dir_cambio == "up", "green",
                   ifelse(cambios_ranking$dir_cambio == "down", "red", "gray")),
    bold = ifelse(cambios_ranking$cambio_rank != 0, TRUE, FALSE)
  ) %>%
  column_spec(5, 
    color = ifelse(cambios_ranking$dir_pct == "up", "red",
                   ifelse(cambios_ranking$dir_pct == "down", "green", "black")),
    bold = ifelse(abs(cambios_ranking$pct_cambio) > 10, TRUE, FALSE)
  ) %>%
  row_spec(0, background = "#04376B", color = "white", bold = TRUE)

Interpretación: La tabla confirma que la estabilidad en el tope del ranking es engañosa, las enfermedades cardíacas y el cáncer permanezcan en primero y segundo lugar no significa que el perfil epidemiológico no haya cambiado. Las cardíacas caen un 10.7% en muertes absolutas la única causa del top 5 que baja mientras que el cáncer sube 9%, una diferencia significativa entre dos condiciones que comparten el podio.

El dato más revelador no es el de la causa más letal sino el del mayor crecimiento: el Alzheimer sube un 172.6%, más del doble de muertes en 18 años. Esto supera con creces cualquier otra causa y plantea una pregunta incómoda, ¿se están destinando recursos suficientes a la investigación y cuidado de enfermedades neurodegenerativas, dado que ya representan la sexta causa y siguen escalando?

Las lesiones no intencionales, con un incremento del 73.7%, también superan el promedio. Su salto del puesto 5 al 3 no es solo un reordenamiento estadístico desplaza al stroke, que desciende con reducción real de muertes del 12.5%, lo que indica que las mejoras en el manejo del ACV conviven con un deterioro en las condiciones que generan accidentes y sobredosis.
